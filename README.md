## 🌟 Ключевые преимущества

1. **Zero-Upload (Никаких мучений с загрузкой 100+ МБ архивов):**
   - Блокнот генерирует студийный датасет из 100+ аудиоклипов Светланы (24 кГц моно PCM) прямо внутри Colab за **50 секунд** через `edge-tts`.
2. **Точный контроль ударений (+):**
   - `вдов+ы` (род. падеж) vs `вд+овы` (мн. число)
   - `перво+образ` (корень «-о́браз»)
   - `стор+ицей` (литературная норма)
   - `в+ерхом неприличия`
   - `обр+ёк`, `опекун+ам`, `тяжелобольн+ом`
3. **Быстрое скачивание базовых моделей:**
   - Используется многопоточная докачка через `aria2c` (~400 МБ/с).
4. **Готовые веса:**
   - После обучения веса упаковываются в архив `svetlana_custom_weights.zip` для локального использования.
